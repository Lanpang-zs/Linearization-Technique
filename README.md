Polynomials: These are the specific polynomials for the 3-round and 4-round versions of Ascon-XOF.

Source_code: Code incorporating linearization techniques for 2, 3, and 4 rounds, respectively.

get_polynomial.py is used for obtaining specific polynomials.

min_gussed_var.py is used to minimize the number of guessed variables while fixing the number of linear output bits.

check_free_var.py is used to check whether the free variables in X_0^1 are included in the linear output bits.
